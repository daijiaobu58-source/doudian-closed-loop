# 各节点输出标准与模板（v2）

本文件定义六个节点的详细输出标准（v2 重构版）。产出时严格按模板结构，数据缺失处标注「假设依据」。每个节点按「输入 → 动作 → 输出 → 放弃条件」执行。

## 阶段权重提示

执行任何节点前先确认当前阶段（起号期/放量期/稳定期/清仓迭代期），按该阶段权重分配精力：
- 起号期：聚焦 1-2 款，内容撬自然流，3 天复盘节奏
- 放量期：素材验证后千川放量，周复盘
- 稳定期：老品保量降佣，新品接力防断档，月复盘
- 清仓迭代期：清仓价/直播清仓/组合优惠，复盘整批品

## 【选品】

**前置**：必须读取上一轮复盘结论（排除项/必含项）与黑名单；禁止重复推荐黑名单中的品。

**输入**：店铺信息（类目/价格带/供应链/预算）、复盘约束（排除项/必含项）、黑名单、可用数据源账号

**动作**：
1. 数据源取数 ≥2 个交叉验证：巨量算数搜索指数趋势（90 天）、罗盘类目 TOP、精选联盟热销榜、飞瓜/蝉妈妈（销量/动销率/达人数/类目退款率）
2. 六维评分（权重可调）：市场需求 20% + 竞争度 15% + 全口径毛利 20% + 体验分风险 15% + 达人供给 15% + 季节窗口 10% + 内容可拍性 5%
3. 全口径毛利按公式计算（见记忆库模板第六节）
4. 季节判定：搜索指数峰值后 >30 天下滑 → 不入池

**输出**：候选品 ≥5 个，每个包含：
- 品名
- 建议价格带
- 全口径毛利（含计算过程，无真实成本标注假设依据）
- 竞争度评分（1-5，1=蓝海，5=红海）
- 内容可拍性评分（1-5）
- 体验分风险（低/中/高，依据类目退款率/品质退货率）
- 达人供给（充足/中等/不足，依据精选联盟活跃达人数）
- 数据来源（≥2 个，注明待校准）
- 综合判定：首批测试 / 合规确认后上 / 供应链确认后上 / 第二梯队 / 降级节点款 / 淘汰
- 结合预算给出首批测款数量建议（预算小优先 1-2 款）

**放弃条件（硬淘汰线，任一命中即淘汰）**：全口径毛利<售价15%（或<8元）；类目平均退款率>20%且无改善手段；活跃达人<100；≥2 数据源无趋势支撑。

**决策门1（选品→上架）**：全口径毛利≥15% + ≥2数据源 + 体验分风险低 + 资质可办 → Go；证据弱但有毛利 → 有条件 Go（只上1个测试SKU）；否则 No-Go 回选品池。

## 【上架】

**输入**：选定品、货盘成本、资质材料、平台当期活动日历

**动作**：
1. 关键词池取数：巨量算数热搜词 + 罗盘搜索分析 + 竞品 TOP20 标题词频 → 主词+属性词+场景词组合 3 组标题
2. SKU 三款结构：引流款（售价≈成本×1.2-1.5，走量拉评价）/ 承接款（主推，目标70%销量）/ 利润款（组合装/大规格/赠品升级，毛利≥40%）
3. 定价节奏：前 7 天活动价（低于日常 10-20%）+ 店铺券（门槛≈客单价×1.1）+ 评估是否报秒杀/满减
4. 图文免佣：上架同步发布图文素材（以平台当期政策为准）
5. 资质报白清单逐项核对：类目准入 → 证照 → 检测报告 → 委托加工协议 → 进口报关

**输出**：完整上架包，每个品含：
- 3 组标题（标注埋入的关键词与来源）
- 5 张主图文案脚本
- SKU 定价表（引流/承接/利润三款，含盈亏平衡测算）
- 活动节奏（前 7 天活动价 + 优惠券门槛 + 是否报活动）
- 资质清单核对结果
- 达人佣金建议（如精选联盟佣金率，按品类给区间）

**放弃条件**：资质缺项无法报白 → 不上架；定价重算后毛利<15% → 换定价或放弃。

**决策门2（上架→推广）**：上架 3-7 天有自然曝光（>0）+ 商品卡 CTR≥2%（经验基准，需校准）+ 无违规/差评异常 → Go；否则先优化（换主图/标题/价格表达）再测，3 轮无效 → 判品不行回选品。

## 【优化】

**输入**：罗盘分渠道数据、体验分、品质退货率、店铺历史基准

**动作**：
1. 分渠道漏斗（抖音口径，不是货架口径）：
   - 商品卡：曝光 → 点击 → 转化 → UV价值
   - 短视频：播放 → 3秒完播 → 5秒完播 → 点击 → 转化
   - 直播：观看 → GPM/千次观看成交 → 互动 → 转化
   - 搜索：关键词维度
2. 关键指标：CTR、CVR、UV价值、GPM、退款率、品质退货率、体验分
3. 数据窗口分级：冷启动 0-3 天（日级）/ 测款 3-7 天 / 放量后 7 天 / 稳定期 14 天
4. 3 天素材迭代小循环：每 3 天迭代一轮（换开头3秒/主图/标题/价格表达），做 A/B
5. 基准来源：罗盘类目均值或店铺历史 30 天中位数；无法获取标注「需校准」

**输出**：每环四要素诊断表——**数据基准 + 你的数据 + 差距 + 具体修改动作**（分渠道呈现，数据缺失时给基准和动作，标注待回填）。

**放弃条件**：连续 3 轮优化无改善（如 CTR 仍<基准一半）→ 判定品或内容方向错误，走决策门回退。

## 【推广】

**输入**：已上架品、素材（短视频/图文）、全口径毛利参数、预算、体验分

**动作**：
1. 保本 ROI 倒推：保本ROI = 1÷(1−毛利率−佣金率−扣点−退货损耗率−广告服务费)；目标ROI=保本×1.3
2. 冷启动两段：先随心推测素材（100-300 元/条，3秒完播、点击率达标）→ 素材验证后再千川放量；禁止上来就直投
3. 四路径分流：
   - 短视频：自然流+随心推测素材
   - 商品卡：标题/主图/价格优化
   - 直播：起号期先达播带量
   - 达人分销：精选联盟建佣+寄样，腰部（10-50万粉）为主战场
4. 计划生命周期：测试期（消耗超 2×保本ROI 对应 GMV 无成交 → 关停）/ 放量期（ROI≥目标 → 复制计划+预算日增 20-30%）/ 衰退期（ROI<保本连续3天 → 关停）

**输出**：
1. 素材矩阵：3 条短视频脚本（每条含：前 3 秒钩子、分镜、口播文案）+ 图文选题
2. 千川计划表：预算分配、定向、出价策略、止损线（注意千川执行需用户在后台操作，Agent 只读盯盘）
3. 达人名单：10 条邀约话术按头部/腰部/素人分组，给出佣金区间与筛选字段

**放弃条件**：素材 3 天无起量（播放<1000 或 3 秒完播<30%，需校准）→ 换素材；计划触发关停线 → 关停不恋战。

**决策门3（推广→复盘）**：素材达标（3秒完播≥30%，需校准）+ ROI≥保本 或 转化率连续上升 + 体验分≥4.5 → 放量 Go；否则缩预算/降佣；连续 2 周期 ROI<保本 → 止损清仓 + 黑名单。

## 【复盘】

**输入**：全周期真实数据（流量/转化/退货/体验分/投放）

**动作**：
1. 目标 vs 结果（指标对比表）
2. 归因决策树（按顺序排除，不是单因归因）：
   ① 流量结构异常？（自然/付费/达人占比）→ ② 承接异常？（CTR/CVR）→ ③ 品与体验异常？（退款率/品质退货率/差评词）→ ④ 体验分异常？（评分/违规）
3. 沉淀两类约束：
   - 排除项（失败原因 → 黑名单 + 失败阶段 + 是否可逆）
   - 必含项（成功要素 → 爆品要素库：人群/素材类型/价格带/达人类别/佣金率）
4. 止损决定：触发止损线（如连续 2 周期 ROI<保本）→ 清仓流程

**输出**：标准复盘报告，必须包含：
1. **目标 vs 结果**（指标对比表）
2. **归因决策树结论**（定位到具体层级）
3. **经验沉淀表**（可复制的经验 + 需规避的坑）
4. **下一轮选品的 3 条方向**（排除项/必含项写入记忆库）
5. **体验分复盘**（期初/期末 + 品质退货率 + 违规记录）

**写回**：复盘结论必须写入记忆库的复盘表（含排除项/必含项），供下一轮【选品】强制读取。

**放弃条件**：无（复盘是强制环节，再差也要做，它是唯一能阻止重复踩坑的机制）。

## 通用

- 所有产出先过合规红线扫描（极限词/功效/价格/诱导/资质/违禁六类）
- 权限分级：查询分析自动执行；写店铺后台动作必须用户确认；刷单/改评价/站外导流明令禁止
- 涉及 API 自动操作只给方案，不假装已执行
- 每个节点产出后，主动向用户索要真实数据回填记忆库
- 行业基准给不出时标注「需用店铺历史数据校准」
