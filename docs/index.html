四阶段打法，不是一套流程打天下

店铺在不同阶段，各节点权重和动作完全不同。

0-30 天

起号期

跑通 1-2 个品 + 素材模型 + 体验分≥4.5。3 天复盘节奏，先内容撬自然流。

31-90 天

放量期

爆品放量，ROI ≥ 保本×1.3。素材验证后再进千川，周复盘。

91-180 天

稳定期

稳量 + 降佣 + 新品接力防断档，月复盘。

随时

清仓迭代期

清仓价 / 直播清仓 / 组合优惠，整批品复盘沉淀。

三分钟装好，开始用

技能包是纯文本知识包：不装程序、不碰店铺后台。三种安装位，内容一致。

豆包专业版（推荐，体验最完整）

把技能包文件夹放进豆包的技能目录，新开对话即可。

1. 把 skills/doubao-doudian-closed-loop 整个文件夹
   放进豆包的「技能存放目录」（设置-技能 可查看）
2. 重新打开对话窗口，让系统重新扫描技能
3. 输入：用抖店闭环运营工作流
4. 回答 4 个初始化问题，即可开始

Claude Code

克隆本仓库后，把技能放进项目的 .claude/skills/ 目录（或用 Add Skill 添加）。

git clone <本仓库地址> && cd <你的项目>
mkdir -p .claude/skills
cp -r <仓库>/.claude/skills/doubao-doudian-closed-loop .claude/skills/
# 然后在 Claude Code 里输入：
# 用抖店闭环运营工作流
  • 仓库根目录的 CLAUDE.md 已写好入口指引，clone 到项目后自动生效
  • 记忆库《XX店铺_记忆库.md》自动生成在你的项目目录

数据纪律与合规边界

这是刻意设计的安全边界，不是功能缺失。

数据不造假

AI 没有你的店铺后台权限。所有数字来自你提供、可复现数据源（巨量算数 / 罗盘 / 精选联盟 / 飞瓜），或明确标注「假设依据」。

写操作必须人工确认

上架 / 改价 / 投放 / 回复消息，AI 只给方案，由你在后台操作。刷单、改评价、站外导流明令禁止。

合规红线自动拦截

极限词 / 功效宣称 / 价格 / 诱导话术 / 资质 / 违禁品类六类红线，每次输出前自动扫描。
