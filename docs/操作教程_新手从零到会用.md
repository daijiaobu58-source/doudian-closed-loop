## 第 1 课：安装与初始化（10 分钟）

### 1.1 安装（选一种）

**方式 A（推荐，豆包专业版）**：
1. 把 `doubao-doudian-closed-loop` 整个文件夹放进技能目录（设置-技能里可查看"技能存放目录"）
2. 关掉对话窗口重新打开（让系统重新扫描技能）
3. 新开对话，输入：**「用抖店闭环运营工作流」**

**方式 B（其他 AI 工具）**：
1. 把 `SKILL.md` 全文粘贴进工具的"技能/自定义指令"配置
2. 把 `references/node-output-specs.md` 和 `assets/memory-template.md` 作为附件挂载
3. 开始对话，输入：「用抖店闭环运营工作流」

**方式 C（最快试用，不装任何东西）**：
把 `SKILL.md` 正文直接粘贴到对话里当角色设定，然后说「用抖店闭环运营工作流」。

> 不确定装没装成功？直接输入「用抖店闭环运营工作流」，如果 AI 开始问你类目、价格带这些问题，就说明装好了。

### 1.2 初始化 4 问（第一次用必答）

装好后 AI 会问你 4 个问题，**按真实情况回答**：

| 问题 | 怎么答（示例） |
| --- | --- |
| 类目是什么？ | 宠物食品 / 女装 / 零食 / 美妆 / 家居… |
| 主打价格带？ | 100-300 元（你卖得最多的客单价区间） |
| 供应链是什么？ | 自有或稳定货源 / 一件代发 / 混合 |
| 月推广预算？ | 5000 元以下（每月打算投多少钱） |

答完后，AI 会在你的项目目录生成《XX店铺_记忆库.md》，并告诉你当前店铺处于哪个阶段（新店默认=起号期 0-30 天）。

**验证初始化成功**：对 AI 说「帮我选品」，如果它给出的候选品里带"全口径毛利、体验分风险、达人供给、数据来源"这些维度，说明 v2 完整版已生效。

## 第 2 课：认识工作流长什么样

这个工作流把抖店运营拆成 6 个节点，像流水线一样循环：

```
选品 → 上架 → 优化 → 推广 → 复盘 →（反哺）选品
```

**三个核心概念，必须懂：**

**① 四阶段（店铺生命周期）**：你的店在不同阶段，各节点要做的事不一样
| 阶段 | 时间 | 重点 | 怎么进 |
| --- | --- | --- | --- |
| 起号期 | 0-30 天 | 跑通 1-2 个品、拉体验分 | 新店默认 |
| 放量期 | 31-90 天 | 爆品放量、ROI 达标 | 体验分≥4.5 且跑出首个 ROI≥保本 的品 |
| 稳定期 | 91-180 天 | 稳量、新品接力 | 连续 2 个月稳定 |
| 清仓迭代期 | 随时 | 清库存、止损 | 有品触发止损线 |

**② 三道决策门（Go/No-Go）**：每个节点往下走之前，AI 会帮你把关——数据不够就拦下来，不让你盲目烧钱
- 门1 选品→上架：毛利达标 + 数据源够 + 资质能办，才上架
- 门2 上架→推广：上架 3-7 天有自然流量 + 点击率达标，才投流
- 门3 推广→复盘：素材达标 + ROI≥保本，才放量；连续 2 周期亏 → 止损

**③ 记忆库（你的店铺档案）**：AI 每次都会读它再干活，干完写回去。它记着你的爆品、复盘、黑名单、成功经验，保证下一轮不重复踩坑。

## 第 3 课：选品节点怎么操作

### 3.1 怎么说
```
进入选品节点，帮我出候选品
```
或更具体：
```
帮我选品，预算有限，先出 3 个值得测的款，要带全口径毛利和竞争度
```

### 3.2 会得到什么
AI 会给你一张候选品清单，每个品至少包含：
- 品名 + 建议价格带
- **全口径毛利**（售价−货品−快递−包材−扣点−佣金−退货损耗−广告损耗）
- 竞争度（1-5，1=蓝海，5=红海）
- 内容可拍性（1-5）
- 体验分风险（低/中/高）
- 达人供给（充足/中等/不足）
- 数据来源（≥2 个，如巨量算数/罗盘/精选联盟/飞瓜）
- 综合判定（首批测试/待确认/淘汰）

### 3.3 你要做什么
1. **核对毛利数字**：AI 算的毛利基于你给的货品成本。如果你还没给过成本，它会标注「假设依据」——这时候你要把真实货品价、运费、佣金率告诉它，让它重算
2. **看数据来源**：如果某个品的数据来源不足 2 个，AI 会标"低证据"，这类品不要当主推
3. **做决策**：从候选品里选 1-2 款（预算小先测 1 款），回复 AI：「就选 XX 和 XX，进入上架节点」

### 3.4 常见错误
- 直接问"帮我选品"但不给类目 → 先完成第 1 课的 4 问
- 看到毛利 40% 就高兴 → 一定要看是不是**全口径毛利**（扣完快递佣金退货后的），裸毛利 40% 实际可能只有 8%
- 候选品里有上一轮黑名单的品 → 正常，AI 会自动排除，你看到也没关系

## 第 4 课：上架节点怎么操作

### 4.1 怎么说
```
进入上架节点，帮我把 XX 做上架包
```

### 4.2 会得到什么
一个完整上架包：
- **3 组标题**（含埋入的关键词，词来自搜索数据）
- **5 张主图文案脚本**（第一张怎么吸引点击、后面怎么讲卖点）
- **SKU 定价表**：引流款（低价走量）/ 承接款（主推扛销量）/ 利润款（高毛利）
- **活动节奏**：前 7 天活动价、优惠券门槛、是否报秒杀/满减
- **资质清单核对**：你的类目要办哪些证照、缺哪项

### 4.3 你要做什么
1. **核对资质清单**：AI 会列出你类目要办的资质（如宠物食品要《饲料生产许可证》、检测报告）。**缺一项就不能上架**——这是决策门1 的硬条件，别跳过
2. **确认 SKU 定价**：检查引流款是不是真的便宜（走量用）、利润款毛利是否≥40%，不达标让 AI 调整
3. **执行上架**：把标题、主图、SKU 填到抖店后台（AI 不能替你操作，这是设计好的合规边界）
4. **同步图文**：上架同时把图文素材发出去（抖音对图文有流量扶持，新店撬流量的最低成本路径）

### 4.4 上架后第 3-7 天
回来说：「进入优化节点，帮我看看 XX 上架后的数据」——AI 会先检查**决策门2**：有没有自然曝光？点击率到没到 2%？没到就先优化，别急着投流。

## 第 5 课：优化节点怎么操作

### 5.1 怎么说
```
进入优化节点，帮我诊断转化漏斗
```
或指定渠道：
```
优化节点，帮我看看短视频的 3 秒完播和点击率，哪里掉得厉害
```

### 5.2 会得到什么
分渠道的四要素诊断表（每个环节都给你）：
```
曝光 → 点击 → 转化 → UV价值
基准：类目均值 2%  |  你的数据：1.2%  |  差距：-0.8%  |  动作：换主图 A/B 测试
```
注意：优化是**分渠道**看的（商品卡/短视频/直播/搜索 各看各的），不是一个大漏斗。短视频看 3 秒完播、5 秒完播；直播看 GPM（千次观看成交）；商品卡看点击率和 UV 价值。

### 5.3 你要做什么
1. **先给数据**：把罗盘后台的真实数据贴给 AI（曝光、点击、成交、退款）。不给数据它只能给基准和动作，标注"待回填"
2. **按动作执行**：AI 说换主图你就换主图，说改开头 3 秒你就重拍开头。每次只改一个变量，3 天后回来看效果
3. **3 天一个小循环**：冷启动期每 3 天迭代一轮素材，做 A/B 对比，别等 7 天

### 5.4 什么时候停
连续 3 轮优化没改善（点击率还是基准的一半以下）→ AI 会建议判品不行，走决策门回退到选品，换品。**别恋战**，这是最省钱的止损。

## 第 6 课：推广节点怎么操作

### 6.1 怎么说
```
进入推广节点，帮我出 XX 的推广方案
```
或指定方向：
```
推广节点，帮我写 3 条短视频脚本 + 千川计划，预算每天 200
```

### 6.2 会得到什么
1. **素材矩阵**：3 条短视频脚本（每条含前 3 秒钩子、分镜、口播文案）+ 图文选题
2. **千川计划表**：预算分配、定向、出价策略、止损线（含**保本 ROI 倒推**：保本ROI = 1÷(1−毛利率−佣金率−扣点−退货损耗率−广告服务费)，目标 ROI = 保本×1.3）
3. **达人名单**：10 条邀约话术，分头部/腰部/素人三组，含佣金区间

### 6.3 你要做什么
1. **先测素材，再放量**（铁律）：
   - 第一步：短视频+图文先发，随心推小额（100-300 元/条）测素材
   - 第二步：看 3 秒完播、点击率，达标了才进千川放量
   - 别上来就直投——那是给平台送钱
2. **执行投放**：千川计划需要你在后台操作（AI 只读盯盘，不能替你投）。AI 给的计划表里每个计划都标了止损线，**触发就关停，不恋战**
3. **达人分销**：按 AI 给的名单和话术去邀约，腰部达人（10-50 万粉）是主战场，佣金按 AI 建议区间设置

### 6.4 决策门3 检查
投了一两周后，回来说「进入复盘节点」。AI 会先检查：素材达标了吗？ROI≥保本吗？体验分≥4.5 吗？达标 → 放量；没达标 → 缩预算继续测。

## 第 7 课：复盘节点怎么操作

### 7.1 怎么说
```
进入复盘节点，出本周复盘报告
```

### 7.2 会得到什么
标准复盘报告，五部分：
1. **目标 vs 结果**（指标对比表：GMV/ROI/退款率/体验分，计划 vs 实际）
2. **归因决策树结论**（按顺序定位问题：流量结构→承接→品与体验→体验分）
3. **经验沉淀表**（可复制的经验 + 要避开的坑）
4. **下一轮选品 3 条方向**
5. **体验分复盘**（期初/期末变化）

### 7.3 你要做什么
1. **给全数据**：流量占比、CTR/CVR、退款率、体验分、投放消耗，有多少给多少
2. **确认 AI 写的两类约束**：
   - **排除项**（失败品 → 进黑名单，下一轮选品自动避开）
   - **必含项**（成功要素 → 进爆品要素库，下一轮选品自动复用）
3. **确认止损决定**：如果 AI 判断某品触发止损线（如连续 2 周期 ROI<保本），决定要不要清仓
4. 复盘结论 AI 会自动写进记忆库，你确认无误即可

### 7.4 为什么复盘最重要
复盘是唯一能阻止你重复踩坑的机制。不做复盘，下一轮选品还是"凭感觉"；做了复盘，AI 会强制避开黑名单、复用成功要素。**再忙也要做，哪怕只是 10 分钟。**

## 第 8 课：数据维护与记忆库（每天 5 分钟）

### 8.1 记忆库是什么
你的店铺档案，AI 每次干活前先读它、干完写回它。文件是《XX店铺_记忆库.md》，放在你的项目目录。

### 8.2 需要你维护的数据（越真实越好用）

**每天（1 分钟）**：把店铺后台数据贴给 AI（或填进飞书表格）：
```
今天的成交：XXX 元，订单 XX 单，曝光 XX，点击 XX，退款 XX 单
```
**每周（5 分钟）**：做一次复盘（第 7 课）
**每款品上架/下架时**：更新爆品表和黑名单

### 8.3 进阶：飞书多维表格数据中枢（可选）
不想每天打字？用飞书多维表格：
1. 建 7 张表：店铺信息、候选品池、爆品表、复盘表、爆品要素库、黑名单、每日数据采集
2. 每天在「每日数据采集」填数据（可建表单，手机上 1 分钟填完）
3. 对 AI 说「读取我的每日数据表，诊断本周漏斗」，AI 直接读表分析
4. 进阶配置：ROI 低于目标线自动提醒、每周日自动复盘提醒
5. 没有飞书也能用：直接贴数据给 AI，效果一样

## 第 9 课：合规红线与权限（必须懂）

**六类红线，AI 会自动拦截，你也要自己留意：**

| 红线 | 例子 | 后果 |
| --- | --- | --- |
| 极限词 | 最/第一/100%/纯天然/顶级 | 违规下架、扣分 |
| 功效宣称 | 食品说"治肠胃病" | 虚假宣传处罚 |
| 价格红线 | 虚构原价/划线价 | 价格违规 |
| 诱导话术 | "不买就亏""先拍后付" | 违规 |
| 资质缺失 | 没办证就上架 | 报白不通过 |
| 违禁品类 | 未备案保健食品/医疗器械 | 直接下架 |

**权限分级（记住这三点）**：
- AI 能自动做：查数据、分析、写方案
- 必须你亲手做：上架、改价、投放、回复消息（AI 只给方案，不假装执行）
- 永远不能做：改评价、删差评、刷单、站外导流（这些是违规，AI 不会帮你做）

## 第 10 课：常见问题

**Q1：AI 给的数据是真实数据吗？**
不是它编的——它没有你后台权限。所有数字要么来自你提供的，要么来自公开数据源（巨量算数/罗盘/精选联盟/飞瓜），要么明确标注「假设依据」。给的数据越真实，建议越准。

**Q2：基准值（点击率 2%、3 秒完播 30%）准不准？**
这些是行业经验基准，AI 会标注「需用店铺历史数据校准」。跑完第一个 30 天，用你自己的真实数据让 AI 回写校准。

**Q3：我没时间天天维护怎么办？**
最低配置：每周做一次复盘 + 每天花 1 分钟贴数据。实在没时间，至少每周贴一次数据、做一次复盘，AI 也能工作。

**Q4：AI 能不能自动帮我上架/投放？**
不能，这是刻意设计的。写操作必须你确认后手动执行，防止违规和资金损失。

**Q5：换了类目（比如从女装换零食）能用吗？**
能，技能包品类无关。换类目后重新初始化 4 问即可，记忆库清空重建。

**Q6：跑完一轮没效果怎么办？**
按流程走：先看复盘归因（是品/内容/投放/价格哪环问题），别急着换品。连续 3 个品 No-Go 说明店铺定位或供应链有问题，先检查这个。
